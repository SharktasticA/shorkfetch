# SHORKFETCH 0.4.0

- Added colour palette field option! It is enabled by default and controlled with the `clrs` field for `--fields`.
    - If you have already saved a configuration before, you will need to add it manually or use `--reset` to reset SHORKFETCH to default settings.
- Added support for Nix/NixOS.
- Fixed GCC -Wformat-truncation warnings during compilation.
- Fixed configuration saving silently failing if `$HOME/.config/` doesn't exist.
- Stopped terminal emulation name detection from trying to use shell script names when walking through parent processes.
- Minor internal CPU handling changes.
- Improved multi-CPU configuration detection by using CPU physical ID counting and a new K8-based AMD Opteron-specific check.
- Improved how clock speeds are removed from CPU model names.
- GPU names extracted from a CPU model name are now cleaned.
- Added the microarchitecture names to Intel Pentium 4 (desktop), Pentium D, Pentium M and (pre-Yonah) Celeron M model names to help differentiate them all from their respective variants.
- Added missing "M" to the affected Yonah-based Intel Celeron M model name.
- Added missing "Pentium S" to affected Intel Pentium Dual-Core Mobile ULV model names. For example, Intel Pentium SU2700 normally identifies as "Intel U2700".
- Added missing "S" to affected Intel Core 2 Duo LV model numbers. For example, Intel Core 2 Duo SL9600 normally identifies as "Intel Core 2 Duo L9600".
- Removed "Dual-Core" and "Quad-Core" from affected AMD Opteron model names. 
- Larrabee-based Intel Xeon Phis that lack a meaningful model name are given a new one. For example, Intel Xeon Phi 7110P normally identifies as "0b/01", so it now gets the name "Intel Xeon Phi (Knights Corner)".
- Corrected the suffix placement on affected Nehalem and Westmere-based Intel Core model names. For example, Intel Core i3-380UM normally identifies as "Intel Core i3 U 380".
- Added missing "-" to affected Sandy Bridge-based Intel Xeon E3 model numbers between "E3" and the following four-digit number. For example, Intel Xeon E3-1230 normally identifies as "Intel Xeon E31230"
- Removed rogue "0" from affected Sandy Bridge-EP-based Intel Xeon E5 model names.
- Fixed Bulldozer-based AMD FX from being detected as in a multi-CPU configuration when they weren't.
- Replaced "V" with "v" on affected Ivy Bridge-based Intel Xeon version numbers.
- The 500MHz Intel Atom variant for the Intel Edison is given a new model name - from "Intel 4000" to "Intel Atom Z34xx (Edison)".
- Cleaned up generic naming found on some Broadwell and Skylake-based Intel Core model names (likely due to hosting/virtualisation platforms).
- Fixed GPU name from CPU extraction failing with AMD A4-9120e.
- Compact mode now condenses "Core mX" to "mX" and "Core Ultra" to "CU" for affected Intel model names.
