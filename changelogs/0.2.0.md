# shorkfetch 0.2.0

- Major internal restructuring.
- Added `--version` argument.
- Slightly improved how screen physical size is rounded.
- Some efficiencies made when using `xrandr` for grabbing screen specs.
- Added rudimentary POWER and RISC-V CPU name parsing support.
- Fixed AMD K6 CPU model name replacements not applying.
- AMD K6-2+ and K6-III+ are now differentiated thanks to reading stepping.
- IDT WinChip 2A is now differentiated from 2-3D thanks to reading stepping.
- Intel Pentium II Deschutes and Celeron Covington are now differentiated thanks to reading cache size.
