# SHORKFETCH 0.6.0

## Usage
- SHORKFETCH can now text-wrap its output, meaning it can be run on far smaller terminal sizes than before without resulting in ugly, art-breaking hard breaks or cut-off output.
- Compact mode now has its own, smaller SHORK ASCII art to save more space than before.
- The separator between the "user@host" header and the rest of the fields is now optional. It is still present by default, but it is a `---` (separator) field you can remove via `--fields`.
   - If you have previously used SHORKFETCH and saved your configuration, the separator will be missing until you manually add it back via `--fields` or reset your configuration with `--reset`.
- All "bold_" prefixed colour names are renamed to "bright_" in documentation and are accepted by `--colour`. This was done to match their real ANSI escape code colour names. `--colour` will still accept "bold_" prefixed names, though.
- Added the `--no-esc` (no-escape-codes) parameter, which prevents SHORKFETCH from using any ANSI escape codes. This increases compatibility with stdin parsers that do not handle such codes, like [gay](https://github.com/ms-jpq/gay), at the expense of losing the text-wrapping feature, all colour output and the colour palette field.
- Removed the `--force-art` parameter. The aforementioned text-wrapping feature means SHORKFETCH no longer hides the SHORK ASCII art when the terminal is too small, thus this is no longer needed.

## Packages
- Fixed an issue where a leading ":" is present when in compact mode and no deb/dpkg packages are found.

## CPU
- Fixed a segmentation fault that could occur when SHORKFETCH tries to find an ARM processor index count.
- A thread count for ARM CPUs is more likely to be found.
- Generic "ARMvX-compatible" model names are overridden with a cleaner name.
- The "Arm" implementer name is no longer added to generic "ARMv" model names.
- IBM pSeries and PowerNV POWER model names are given the "IBM" vendor name if it is missing.
- PowerPC CPUs are now given "PowerPC" in their model name and their core/thread count if they were missing. Additionally, for Apple G3-G5 hosts, the "G" generation number is also added if it's inferred via either the PVR or the IBM model number. For example, an iBook G3's model "750CX" now becomes "PowerPC G3 (750CX)".
- Replaced Motorola POWER model names with the "Motorola" vendor name and an MCPxxx model number if the latter is found in the machine name. For example, model "740/750" with machine name "Mesquite cPCI (MCP750)" becomes "Motorola MCP750".
- The STI Cell Broadband Engine model name is shortened to "Cell/B.E." and given the host type in brackets if such was found in the platform or machine name. For example, model "Cell Broadband Engine" with platform name "PS3" becomes "STI Cell/B.E. (Sony PS3)".
- Fixed multi-CPU detection for Intel Pentium Pro and III.
- Added missing "Tualatin" microarchitecture name to affected Intel Pentium III model names.
- Differentiated Intel Pentium III-S model name from III.
- NetBurst-based Intel Celerons now receive Pentium 4 microarchitecture names in their model names instead of Xeon.

## Disks
- Added the disks (`dsk`) field. This lists up to ten hdX, sdX and nvmeXnX fixed disks and their size.

## Colours
- Added the base (`clba`) and bright (`clbr`) ANSI escape code 8-colour palette fields. They allow you to place half of the existing 16-colour (`clrs`) palette independently from each other.
