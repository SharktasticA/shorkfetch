# SHORKFETCH 0.6.4

## Building

- Renamed the undocumented `EMBEDDED` build flag to `SHORK_DISKETTE` to better highlight its usage. This flag is not for regular usage and should generally be ignored - it is used when building the SHORK DISKETTE operating system.
- Implemented some specific bytesize-saving measures by gating code not useful to SHORK DISKETTE's use when the `SHORK_DISKETTE` flag is used.

**Full Changelog**: https://github.com/SharktasticA/shorkfetch/compare/0.6.3...0.6.4
