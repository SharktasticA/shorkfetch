# SHORKFETCH 0.3.0

- Added the `--save` and `--reset` options to control custom configuration saving. The former can be used alongside other options to save them to a configuration file so they are remembered the next time SHORKFETCH is used. The latter resets SHORKFETCH to the default configuration.
- The `--field` option now accepts random order, repeated fields, `---` to denote category separators, and ` ` (single blank space) to denote new lines.
    - The `--categories` option was removed as these changes made it obsolete and allow for finer control of this feature anyway.
- Added the `--colour` option to allow the accent colour to be changed at runtime instead of at compilation time.
- Major internal CPU handling changes.
- Multi-CPU configurations should now be recognised as such and given a prefix indicating how many CPUs are present.
- Added back missing compact mode specific CPU name customisations lost between version 0.1.1 and 0.2.0.
- Socket 4 and 5 Intel Pentium OverDrives are now distinguished from regular Pentium P5 or P54C via clock speed.
- Removed hardcoded "Dual-Core" substrings from any affected Intel CPU model names.
- Removed hardcoded clockspeeds from Intel Pentium D model names.
- Added missing "Duo" to affected Merom-based Intel Core 2 Duo model names.
- Removed rogue "Dual" substring from affected Merom-based Intel Pentium model names.
