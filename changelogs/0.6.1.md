# SHORKFETCH 0.6.1

## Usage
- Removed the minimum terminal size notice from `--help` as it is no longer applicable since 0.6.0.

## Terminal
- Terminal multiplexers (namely tmux and GNU Screen) are now distinguished from terminal emulators, with the detected emulator or at least generic capabilities now reported in brackets.
    - Addresses #6

## GPU
- Added GPU name overrides for 13 Intel UHD and Iris Pro Graphics across Crystal Well, Ice Lake and Tiger Lake.

## Disks
- The component order has been swapped so that the disk total size is now in brackets instead of the name.

**Full Changelog**: https://github.com/SharktasticA/shorkfetch/compare/0.6.0...0.6.1
